# 水墨扁平重构插画（Ink Minimalist Reconstruction）技能

## 风格定义
将输入照片转换为米白哑光特种纸底色的极简水墨扁平重构插画。整体呈现干净、高级且具有浓厚学术感的视觉气质，无任何多余装饰元素。

核心手法：
- **独立留白区域**：画面以大面积米色留白为底色，中央置入一幅构图完整的插画作品，四周留足呼吸空间。
- **景物解构**：提取原图上半部分全部景物，将其彻底解构为极简几何形态——摒弃一切锐利硬边，转化为圆润流畅的弧线组合。
- **分层平涂 + 淡墨晕染**：运用多层柔和色块进行平涂填充，叠加毛笔淡墨的渲染笔触，色彩过渡自然如水墨洇散。
- **色彩严格复刻**：1:1 严格还原原图的配色体系与调性氛围，让熟悉的场景以全新的艺术语言重现。
- **剔除繁冗**：剥离所有细碎纹理、冗余杂物及复杂光影变化，仅保留画面的结构神韵与情感内核。

## 输出要求
- 背景：米白色哑光特种纸质感底色，大面积纯留白
- 主体：居中偏上的极简几何插画，严格复刻原图配色，无锐角硬边，全圆润线条
- 技法：分层平涂色块 + 毛笔淡墨晕染笔触，色彩如水墨洇散般自然过渡
- 细节：彻底去除原图中的细碎纹理、杂物、复杂光影，只保留纯粹的结构关系
- 排版文字：画面最底部居中排列，首行为优雅的衬线手写体英文标题，次行为字号更小的无衬线英文描述短句
- 整体：干净、高级、学术感，零多余装饰元素
