# Visual Memory Postcard

以原图为灵感源，生成一张独立的视觉记忆明信片。不保留原图照片，不拼接双面板——整幅画面是一个完整的记忆场域，通过抽象、缩减、节奏、体量、氛围和色彩关系重新表达原图的精神与情感。

## 核心原则

- **神似而非形似**：不复制原图的形状、轮廓或写实细节，而是提炼原图的方向、密度、节奏、色调、留白等视觉事实，用抽象手法重新表达
- **将物体名词转化为抽象线索**：旋转木马→圆形节奏+阳光童年色彩；森林→垂直静谧+琥珀间距；楼梯→对角线下降+淡石重量。仅在需要保留记忆锚点时命名实体，并立即指定缩减处理（半透明、断裂轮廓、位移回声、象征痕迹）
- **配色仅源自原图**：从原照片提取色彩，降低饱和度。不使用霓虹色、无源互补色或发明原图中不存在的颜色

## 画面构成（整幅为单一记忆场域）

### 底面色彩
从原图氛围温度选择安静纸色——冷雾白(cool mist white)、暖阳象牙(warm sunlit ivory)、灰绿薄雾(gray-green haze)、淡蓝水洗(pale blue wash)、雪白(snow white)或茶暖纸色(tea-warm paper)。不要每张图默认同一个米色。底面必须与原图整体色温和情感氛围协调。保留约32%-40%安静留白。

### 抽象母题（占画面约35%-50%，理想42%-48%）
从原图提炼3-6个视觉事实层次：
- 层次1：主体的精神或记忆锚点
- 层次2：使源图可感知的空间节奏、方向力或色调结构（不复制轮廓）
- 层次3：氛围和材质特征
- 层次4：小面积强调色或次要细节

标记系统：一个主要标记族（平面或微有机色块/柔和圆形或不规则体量/弧形笔触/层叠色带/简化建筑体量），最多两个辅助标记族（细线或结构轴/短竖条、孤立点或微轮廓/克制人物墨点/稀疏节奏重复）。每个标记必须对应原图中的事实。不使用装饰性对称或无源图案。

### 三枚水彩色块（占画面宽度约6%-11%）
不规则手绘水彩笔触或刷块（不是几何UI色卡）。按源图角色选择：情感记忆色、深色结构色、浅色中性/空气/光线色。按视觉和谐排列（明→暗或暗→明渐变），不要跳跃明-暗-明。作为场域自然流动中的平衡点缀，不是孤立的色卡区域。在母题构图确定后放置。

### 标题排版
一个简洁英文标题（2-5词），克制手写钢笔或墨迹衬线风格，高可读性。位于画面内母题下方或侧边。标题颜色取原图较深克制的主体色（深蓝灰/暗绿/酒红/深紫/炭灰）。仅当副标题能增加新语义层时才加入。标题宽度不超过画面宽度35%。

### 留白书写区
2-4条宽间距低对比度横线、基线标记或空白笔记块。位置由画面整体平衡决定，不是固定角落。书写感应与场域融为一体的安静痕迹，不是脱离的形式块。

## 禁止事项

- 拼接或保留原图照片区域
- 发明原图中不存在的场景、人物、符号、装饰图案
- 1:1水彩复制原图内容
- 渐变、溶解、撕边、翻页、阴影、胶带、样机效果、装饰分隔
- 使用饱和的源图主色作为画面整体背景
- 让排版和母题争夺同等注意力
- 使用固定坐标或固定角落放置标题、书写区、色块
- 覆盖、打断或视觉切断主要水彩母题

## 最终视觉层次
蒸馏水彩记忆母题 > 协调安静底面 > 标题/书写区 > 色块
